# Sparsh Saxena — Personal Website

Static HTML/CSS/JS portfolio built for GitHub Pages, Cloudflare Pages, or any static host.

## Files
- `index.html` — page structure, content, SEO metadata and JSON-LD
- `style.css` — responsive design and animations
- `script.js` — loader, nav behavior, mobile menu, reveal animations
- `assets/` — Sparsh photo and Elara logo

## Deploy on Cloudflare Pages
1. Push this folder to a GitHub repository.
2. In Cloudflare Pages, create a project from that repository.
3. Use the repository root as the build directory and leave the build command empty.
4. Deploy.
5. Add a custom domain later from the Pages project settings.

## Deploy on GitHub Pages
Push the files to a repository and enable Pages from the repository's Pages settings using the root of the default branch.
